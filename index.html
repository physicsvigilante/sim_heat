A practical starting path

  1. Inspect an existing case. Open the explorer, choose an arrangement and select a body, boundary, junction or rod. Graph positions show connectivity, not apparatus geometry.
  2. Check what the values mean. Read provenance and units. Positive rod flow follows its authored port direction. Lines between saved samples are visual guides, not computed intermediate physics.
  3. Compare existing evidence. The conductivity comparison uses the saved D2 and D2_K2 runs. It is not a live parameter slider or a new solver launch.

To author a supported model, start with the current authoring guide. The historical H1 foundation contract retains its original design-stage status. See also the viewer and archive guide. Admission is a source check, not permission to execute. A new native attempt needs separate explicit approval.

Open locally

From the repository root, serve this start page and the existing explorer:

python -m http.server 8000 --bind 127.0.0.1

Visit http://127.0.0.1:8000/. No OpenModelica installation is needed for archived playback. See the project guide for development checks.

Restricted linear, lumped heat transfer. No general symbolic/inverse solver or autonomous natural-language simulation. Teacher usability remains unproven.
