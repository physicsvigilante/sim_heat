# H1-N6 — exact algebraic junction equilibrium for area-rod graphs

**Offline-only candidate — not an integrated thermal simulator or native reference.** This milestone adds a reusable, topology-independent rational Dirichlet solver for admitted H1 thermal graphs made entirely of `RodArea` conductors. It reuses the accepted N4 source-exact static-physics checks and N5 graph/port sign assembly without changing either module or the original H1 production engine.

A user provides body-node temperatures as strict ASCII decimal strings. Original maintained boundary temperatures are preserved from the source facts; ownerless junction temperatures are unknowns. For every rod, `q_ab = G(T_a−T_b)`, with positive exact `G=kA/L`. Each ownerless junction must satisfy `Σ q_out=0`. N6 assembles the positive-definite Dirichlet Laplacian and solves that algebraic system with **exact Fraction Gauss–Jordan arithmetic**, checking positive pivots, exact reconstructed original residuals, a passive maximum principle and graph-wide opposite-port cancellation. It then reports solved junction temperatures, oriented flows, prescribed-boundary supplies and instantaneous **conditional** body heating rates.

This is useful for teacher exploration: students can choose body temperatures at an instant, see the physically consistent junction temperatures and compare heat flows without needing to solve a full differential equation. Every body temperature remains an **explicit assumption**. No time integration, native state, DAE trajectory, quadrature, original model-source authority, private scorer recovery or all-grid numerical certificate is implied. The output says `EXACT_JUNCTION_EQUILIBRIUM_ONLY_NO_TRAJECTORY` and retains all native/accuracy/runner booleans false. It is not a PR62 or N3 runner-consumable bundle.

**Deliberate bounded domain:** A graph containing even one `RodCircular` conductor is **refused** here, rather than replacing its mathematically uncertain Pi-dependent G interval by an unjustified midpoint. N5 remains available to inspect circular-rod assumed-temperature trial heat flows. A later independently reviewed interval-safe junction solver can extend the same interface. N6 currently supports up to 20 unknown ownerless junctions with each exact rational intermediate bounded to 16,384 bits; ill-posed or resource-exceeding cases refuse rather than silently approximate.

Strict ASCII full-match numeric syntax accepts ordinary positive decimals and scientific notation but refuses whitespace, underscores and Unicode digits that Python Decimal would otherwise silently accept. Boundary values are not caller-editable. Numeric results are exact rational strings; no rounded decimal is presented as exact physical proof. A solution with `junctionsSolved=0` still means only a consistent algebraic snapshot, not a dynamic solution. Ownerless junctions with >=2 real ports and each connected component anchored to a source/body have already passed N4 admission. N6 tests independent bridge/loop, reversed rod, parallel conductor, isolated-body, malformed-input, and circular-refusal cases.
